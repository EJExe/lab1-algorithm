# Лабораторная работа №1 — Хаммурапи

Консольная игра на C++17. Проект собирается с помощью CMake.

## Сборка и запуск на macOS

Нужны компилятор C++ и CMake.

```bash
cd "/Users/vladislavlasmanov/Documents/УЧЕБА/Algoritms/Lab1"
cmake -S . -B build
cmake --build build
./build/Lab1
```

В CLion или другой IDE с поддержкой CMake откройте папку проекта,
содержащую CMakeLists.txt, и выберите цель Lab1.

## Файлы проекта

- Lab1.cpp — исходный код игры.
- CMakeLists.txt — настройки сборки.
- build/ — автоматически создаваемые файлы сборки.

В начале каждого раунда Enter продолжает игру, q сохраняет её и завершает
программу. Сохранение hammurabi.save создаётся в текущей рабочей папке.
Для продолжения игры запускайте программу из той же папки.
